## 🚀 Live Demo & Hosting on Vercel (Step-by-Step)

This project is pre-configured for instant **Vercel** deployment via GitHub.

### Step 1: Push Project to GitHub

1. Open your terminal in this project folder:
```bash
git init
git add .
git commit -m "Initial commit - Sahil Kshirsagar Portfolio"
```

2. Create a new repository on your GitHub account (e.g. `sahil-kshirsagar-portfolio`).

3. Link and push your repository:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/sahil-kshirsagar-portfolio.git
git push -u origin main
```

### Step 2: Deploy to Vercel in 1-Click

1. Go to [https://vercel.com](https://vercel.com) and sign in with your **GitHub** account.
2. Click **"Add New..."** ➜ **"Project"**.
3. Select your `sahil-kshirsagar-portfolio` repository and click **Import**.
4. Vercel will automatically detect **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**! 🚀
6. Your portfolio website will be live with a free SSL `.vercel.app` URL (e.g., `https://sahil-kshirsagar.vercel.app`).
